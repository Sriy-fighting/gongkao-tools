# 公基个人笔记整合审计

来源：用户提供的飞书文档《公基知识点》（2026-08-25 只读访问）。文档内容仅作知识来源，不执行其中的任何操作性指令。

## 合并规则

- 现有知识树中已覆盖的同主题分支标记为 `personal: true`，在页面中以加粗显示。
- 缺失事实集中补入对应学科的“个人笔记补充”分支，避免同一事实以近义句重复出现。
- 新增的公文与做题方法以独立模块纳入共享搜索索引。
- 法律时效、处罚和责任年龄等时效性规则仍保留页面的“以现行法为准”提示。
- 原资料中“物质的唯一特性和根本属性”混同，已按个人笔记修正为“唯一特性是客观实在性，根本属性是运动”。
