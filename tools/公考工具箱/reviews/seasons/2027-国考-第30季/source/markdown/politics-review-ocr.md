27国考行测模考第30季政治理论复盘
。 1.马哲
。 通过对比实验体现具体问题具体分析是解决矛盾的关键。
。 发挥主观能动性必须以尊重客观规律为前提，违背规律导致失败。
。 认识的反作用: 正确认识促进实践发展，错误认识阻碍实践。
。 2. 实践作为检验真理的标准
。 实践标准具有绝对性 〈确定性) 和相对性 (不确定性) 。
。 相对性: 检验是一个过程，不能一次完成;检验不是一劳永锡的，需随实践发展持续检验。
。 绝对性: 凡是真理终将被证实，凡是廖误终将被驳倒，除实践外无其他标准。
。 应是理论接受实践检验，而非实践接受理论检验。
。 3. 全球人工智能治理体系
。 全球人工智能体系构建: 坚持开放共赢、强化风险意识、倡导多边主义。
。 应用全人类共同价值 (和平、发展、公平、正义、民主、自由) 塑造人工智能价值观，而非
反之。
。 4.服务人民
。 正确政绩观: 以人民为中心， 高质量发展是首要任务。
。 显绩与潜绩: 显绩体现在即将见效的工作，潜绩体现在打基础、利长远的工作。
。 应防止数字出官、官出数字”的恶性循环，而非促成。
。 5.党史与政党地位
。 政党地位: 中国共产党是世界第一大政党。
。 根本属性: 人民性是根本属性，而非一般“重要特征”。
。 6.教育强国建设
。 把握政治、人民、战略属性;高校转型由注重规模向注重质量转变。
。 学龄人口流动方向: 应为流入城镇和薄弱地区需增加资源供给，而非流出。
。 教育经费体制一一实行省级统筹，而非全国统筹 (因各地财政实力和人口波动差异大) 。
。 7. 服务业发展一一服务业发展方向应为数字化、标准化、融合化、国际化，而非*“行业化、互动
化”。
。 8.三农工作与乡村振兴
。 健全财政优先保障、金融重点倾斜、社会参与的多元投入格局。
。 严禁打破集体土地所有权界限搞平均承包。
。 应发展农业适度规模经营，而非单纯扩大规模，强调高质量发展。
。 应节约集约利用农村集体土地，而非城镇集体经营建设用地。
。 9.金融强国建设

## 第3页

。 根本宗旨: 金融是实体经济的血脉，金融服务实体经济是根本宗旨。
。 价值取向: 以人民为中心，金融事业归根到底要造福入民。
。 人民性是根本属性，用"重要”修饰力度不足 “重要就是不重要”原则) 。
。 10. 全国统一大市场
。 完善法律法规，强化刚性约束。
。 有序取消一些行政性限制消费购买规定，而非*所有”。
。 应推广经营主体活动发生地登记，而非注册地登记。
。 应扩大强制性国家标准覆盖面，而非缩小。
。 11. 对外开放
。 全面实行准入前国民待遇加负面清单管理制度。
。 应稳慎拓展金融市场互联互通，而非全面放开。
。 单边开放主要针对最不发达国家，而非发达国家。
。 开放合作是中国式现代化的必然要求，而非“战略安排"。
。 12.海洋经济
。 创新驱动、综合治理; 十八大提出海洋强国部署。
。 推动海洋经济向质量效益型转弯，而非质量规模型。
。 13. 雄安新区建设一一卜解北京非首都功能
。 推进方式: 应分批推进央企、高校、医院疏解，而非统一推进。
。 应以改革创新为动力，要素资源集聚为重点。
。 应推动生产性服务业，而非生活性服务业与新兴产业直接并列。
。 14.电力市场一一电力价格应在合理水平运行。
。 15.粮食安全一一谷物基本自给、口粮绝对安全，而非谷物完全自给。
。 16.城市工作
。 超大特大城市强身健体，中解非核心功能。
。 建设用地配置应差异化，而非均衡化。
。 文化遗产保护应以居民/村民为主体，而非建筑为主体。
。 社保比例应稳步提高，而非快速提高。
。 17.兢减排一一应有序推动高载能产业转移，而非全部;国际协定为《巴黎协定》，非《纽约协
定》。
。 18.全民阅读一一倡导终身学习，而非阶段性学习。
。 19.收入分配一一按劳分配为主体，缩小差距而非拉平差距，扩大中等收入群体规模。
。 20.医疗卫生
。 基本医疗保险为省级统筹。
。 三级医院侧重疑难重症，常见病由基层医疗机构负责。
。 医保支付应差异化，而非统一化。
